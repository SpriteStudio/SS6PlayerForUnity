##  SS6Player for Unity

> [!IMPORTANT]
> 後継の **SpriteStudio Player for Unity** を公開しています。
>
> <https://github.com/cri-middleware/SSPlayerForUnity>
>
> [対応プラットフォーム](https://cri-middleware.github.io/SSPlayerForUnity/ja/setup/install/#対応プラットフォーム)と、[対応環境](https://cri-middleware.github.io/SSPlayerForUnity/ja/setup/install/#対応環境)の Unity のバージョンを確認のうえ、移行してください。
>
> 移行の手順は [SS6Player for Unity からのマイグレーション](https://cri-middleware.github.io/SSPlayerForUnity/ja/migration_from_ss6/) を参照してください。アセットの `.sspj` からの再インポートと、スクリプトの書き換えが必要です。

ドキュメントはこちらです。  
https://github.com/SpriteStudio/SS6PlayerForUnity/wiki
